# Say What Actually Broke

One line of software error copy that tells the user the brutal truth about
what went wrong — and makes them laugh on the way.

> We deleted the backup to save space, then deleted the original to test the backup. There is no step three.

`main.py` writes that line to the harness output file (`entry.txt`).
Standard library only; no dependencies.
